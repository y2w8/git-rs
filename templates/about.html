About

This is my personal Git server where I host my projects and experiments. All repositories here are public and can be cloned over HTTPS: 

git clone https://git.y2w8.online/<repo>

Contributing

If you find a bug or want to send a change, you can generate a patch with Git and email it to yo2w86@gmail.com: 

git clone https://git.y2w8.online/<repo>
cd <repo>
# make your changes and commit them
git commit -am "describe your change"
git format-patch origin/main

Then email the generated .patch file to yo2w86@gmail.com. Some repositories are also mirrored on GitHub, so you can open a pull request or issue there if you prefer.
